# Zaman Yolcusu Yanlış Dönem Dedektörü

## Bu Ne?

Eğer bu kodu çalıştırıyorsan, büyük ihtimalle yanlış zaman çizelgesindesin. 2026'da yaşadığını düşünüyorsun ama aslında 1998'de takılı kalmış olabilirsin. Bu program bunu tespit eder.

Kod çalışır. Rastgele faktörlerle senin "gerçek" yılını hesaplar. Genelde yanlış çıkar.

### Kullanım
```bash
python3 dedektor.py
```

Sonuç çıkarsa panik yapma. Zaten panik yapman da yanlış dönemde olduğunu gösterir.
